# Controlled soak checkpoint

This is a partial M9 reliability run with disposable executables. It does not close or restart ChatGPT and does not establish the actual-target pilot or the complete 24-hour release gate.

The [soak probe](../tools/Relight.SoakProbe/Program.cs) creates isolated shared-session preview data and two distinct runnable copies of `Relight.TestTarget.exe` under ignored `artifacts/soak`. The first simulates launcher handoff; the second spawns a helper that outlives its main process. Both use hidden target windows, exit after 90 seconds, and have a 60-second stability observation period, so the preview can repeatedly recover them without consuming an attempt after stable recovery. The helper is excluded from main-target identity. The probe launches the real WPF/tray executable with the dashboard closed, writes atomic `progress.json` updates every 30 seconds, records CPU, working set, log size, event summaries and shared budgets, then stops only its own Relight process and its copied disposable targets. The test runner does not delete the evidence directory.

Run from a Release build with `dotnet run --project tools/Relight.SoakProbe -c Release -- 1440` for 24 hours. A shorter duration in minutes can validate the harness. Because the targets and Relight run in the current Windows sign-in, this is not a second-session, sleep/lock, or actual ChatGPT test. The probe currently keeps the dashboard closed throughout; UI open/close cycles remain a separate acceptance gap.

On 28 September 2026, a three-minute harness check completed in **190.3 seconds**. Each profile recorded two automatic reservations and dispatches, one stable automatic recovery, one observed disappearance and zero lockouts. Neither budget was locked out; each had one charged attempt in its new episode when the probe ended. Relight used 4.30 CPU seconds (0.282% of eight logical processors), reached a 119.1 MiB peak working set and produced 23,703 bytes of logs. The raw `report.json` and progress record are in ignored `artifacts/soak/20260928-083441-52399a62`. This short run confirms the harness can exercise repeated recovery, handoff and helper filtering; it does not satisfy the 24-hour soak requirement or bound long-term growth.

After adding bounded retries for transient budget-file contention and log-rotation-safe sampling, a second three-minute run completed in **190.2 seconds** with the same per-profile event counts and zero lockouts. Its `progress.json` ended in `Completed`; the runner stopped its own Relight and copied target processes. The raw report is in ignored `artifacts/soak/20260928-084231-231ac325`. The Release build passed with zero warnings/errors, and the full local suite passed **219 tests**.
