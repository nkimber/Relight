# History checkpoint

**Date:** 27 September 2026  
**Scope:** First read-only M7 slice; M7 exit criteria are not met.

The History page now reads Relight-owned JSON Lines files under `%LOCALAPPDATA%\Relight\Logs` without stopping monitoring. It shows the latest 500 matching events with local-time labels, severity, event type, profile, state/attempt summary and expandable UTC/correlation details. Filters cover configured application, minimum severity, event type, optional episode ID and three time ranges (24 hours, seven days, all retained). Refresh is explicit; opening History requests a fresh load. The original log folder can be opened from the page. Export uses the same filters but scans all matching retained records, independent of the display cap, and writes CSV or readable text to a user-selected local file outside Relight's data directory. A temporary file is flushed before replacing the chosen destination; cancellation leaves an existing destination intact.

The storage reader accepts only the journal's exact owned filename pattern and skips reparse-point files. It de-duplicates event IDs, reports malformed lines and returns the latest matching records with a total count, so truncation is visible. A vanished file during retention is skipped. Other I/O failures reach the page as an error. Reads run away from the WPF dispatcher and a superseded read is cancelled.

**Verified locally:** `dotnet test Relight.slnx -c Release --no-restore` passed 75 tests, including reader filtering, latest-result truncation, foreign-file exclusion, corrupt-line reporting, a 505-event export beyond the display cap, CSV quoting, state-file protection and cancellation. `dotnet build Relight.slnx -c Release` passed with zero warnings/errors. `pwsh -File scripts/Test-Shell.ps1` passed the isolated tray lifecycle checks. [Windows CI for filtered export](https://github.com/nkimber/Relight/actions/runs/36347051353) passed its Release build and deterministic subset. The History page and export dialog have not received an interactive visual/accessibility check.

**Remaining:** The page only offers current configured profiles in the application filter; removed-profile history still appears in the unfiltered list but cannot be selected by profile ID in the filter. There is no user-facing overnight summary, diagnostic bundle, notification system, or complete event taxonomy/error categorization. Malformed lines are reported, but files removed by concurrent retention before enumeration cannot be included in an export; AT-25's complete selected-episode guarantee under retention and its full redaction review remain open. The 500-row view is intentionally bounded, while export is not. History is therefore useful for inspecting recent evidence but does not yet meet the PRD's complete morning investigation flow.
