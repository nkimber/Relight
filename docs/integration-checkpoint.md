# Combined acceptance integration checkpoint

**28 September 2026.** Branch `codex/integrated-acceptance` combines the still-open changes from PRs [#1](https://github.com/nkimber/Relight/pull/1)–[#7](https://github.com/nkimber/Relight/pull/7) on `origin/main`. It is a review candidate, not a merged release or a completed milestone. The primary checkout's unrelated uncommitted settings and release work was not copied into this branch.

The combination retains callback-driven executable exit reconciliation, launcher handoff and helper classification, bounded ambiguity diagnostics, the scheduler's missed-heartbeat fallback, live last-good configuration repair, WPF storage-fault checks, simultaneous-failure isolation, and interactive history/diagnostic export checks. Cherry-pick conflicts involved adjacent acceptance rows, independently added UI-test modes and two host-test methods. Both tests and all UI modes were kept; the overlapping policy editor setup now chooses the appropriate inputs for exit-race or ambiguity checks.

On Windows with .NET SDK **10.0.401**, `dotnet build Relight.slnx -c Release` passed with zero warnings and errors. The full `Relight.Core.Tests` Release run passed **247/247** in **16m22s**, including Windows process tests. `pwsh -File scripts/Test-Shell.ps1` passed. Separate isolated WPF UI runs passed for `-ExerciseAmbiguity`, `-ExerciseExitRace`, `-AcceptInitialStart -ExerciseBrokenConfig`, `-AcceptInitialStart -ExerciseCorruptBudget`, `-AcceptInitialStart -ExerciseBlockedLogs`, `-AcceptInitialStart -ExerciseBudgetWriteDenial` and `-AcceptInitialStart -ExerciseHistoryExport`. These runs use disposable targets and preview data directories; they do not prove actual ChatGPT close/relaunch.

The [acceptance matrix](acceptance-status.md) records the scope of each AT result. In particular, AT-19 still needs a real access-denied lookup through WPF; AT-20 needs a physical resume run with the fallback; AT-23 needs disk-full and release-candidate checks. The separate 24-hour soak was still running when this checkpoint was written and uses an earlier isolated preview build. It cannot validate this combined branch. Final release checks, accessibility review, portable package testing and the supervised **ChatGPT-only** pilot in a disposable Windows session remain open under [the development plan](development-plan.md).
