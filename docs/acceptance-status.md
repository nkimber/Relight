# Version 1 acceptance status

**Snapshot:** 28 September 2026, source revision `e4ecbb1`. The source of truth for the required results is [PRD Section 13](PRD.md#13-acceptance-scenarios). This is a scenario-level audit, not a list of implemented features. **Passed** means the stated result was observed at the PRD's controllable-test-target scope. **Not run** means the complete scenario has not been verified, even where a component or a narrower path passed. **Blocked** identifies a known manual prerequisite. A green build or deterministic unit test does not by itself turn a Windows/UI scenario into a pass.

The [manual acceptance checklist](manual-acceptance.md) sets the user-requested order: release validation, a manually reviewed 24-hour soak, then actual ChatGPT recovery last. The matrix must be refreshed against the final candidate after code changes. Beyond AT-01–AT-30, the [development plan](development-plan.md) still requires its APP/MON/CTL/LOG, accessibility, performance and release gates. This audit does not mark M8 or Version 1 complete.
